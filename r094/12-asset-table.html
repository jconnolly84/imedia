Keeping Accurate Records

Every asset, every time

An asset table records each asset's properties, its exact source, its licence or permission, and where it is used. Use the official OCR template.

Properties

Technical

  • Dimensions, resolution, file size, format
Source

Where from

  • Exact URL or 'created by me'
Legal

Licence

  • Copyright, Creative Commons, royalty-free
  • Attribution needed?

Key Terms

Asset table
A record of each asset, its properties, source and licence.
Attribution
Crediting the creator of an asset.
Royalty-free
Licensed for use without ongoing payments.

Good Practice & Watch Out For

✔ Good practice

  • Record assets as soon as you use them
  • Be specific about sources
  • Use the official OCR template

✘ Watch out for

  • Listing a search engine as a source
  • Vague 'where used' entries
  • Leaving licence columns blank
