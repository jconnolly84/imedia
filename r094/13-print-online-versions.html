One Design, Different Outputs

Print

Print needs enough pixels for the physical size – around 300 dpi – usually in CMYK, exported to high-quality formats.

Screen

Screens are measured in pixels, use RGB, and need small, compressed files that load quickly.

Key Terms

Resample
Changing the number of pixels in an image.
Rasterise
Converting a vector into pixels.
DPI
Dots per inch – print resolution.

Good Practice & Watch Out For

✔ Good practice

  • Check pixel dimensions for the print size
  • Export separate versions for print and screen
  • Match the client's required formats

✘ Watch out for

  • Upscaling small images for print
  • Sending RGB-only files to print without checking
  • Using huge files on the web
