Choosing Formats

Right format for the job

Logos are usually kept as vector masters and exported to raster formats (e.g. PNG with transparency) for use on screens and documents.

Vector

SVG, AI, EPS

  • Scalable
  • Small file size
  • Needs compatible software
Raster

PNG

  • Lossless, transparency
  • Fixed pixel size
Raster

JPG

  • Lossy, no transparency
  • Better for photos

Key Terms

Colour depth
The number of bits used for each pixel's colour.
Colour mode
RGB for screens, CMYK for print.
Transparency
Areas of an image with no background.
Scalability
Resizing without loss of quality.

Good Practice & Watch Out For

✔ Good practice

  • Keep a vector master of the logo
  • Export formats that match each use
  • Check file properties after exporting

✘ Watch out for

  • Using JPG for logos that need transparency
  • Enlarging small bitmaps
  • Forgetting software compatibility
