Create the Visual Identity (Logo)

Create your final logo and record the process — the process is the evidence.

Keep your Project Log updated Screenshot as you work Link back to brief + audience

Logo Creation

  • Use appropriate software (Inkscape / Canva / similar).
  • Capture screenshots of key stages and annotate them.
  • Annotate each screenshot: what tool you used, what you did, and why.
  • Export the logo in suitable formats.
Project Log evidence:
Add screenshots and explain what you did and why.

Quick checks

  • Does this link back to the client brief?
  • Does this suit the target audience?
  • Have you taken screenshots during the process?
  • Is your work saved in a sensible, organised folder?
Common mistake:
Only showing the final outcome. Record your process and explain your decisions as you go.

Building a Logo

Vector for logos

Vector tools build logos from paths and shapes, so they scale to any size without losing quality – from a favicon to a billboard.

Tools

Drawing tools

  • Shapes, pen/path, nodes
  • Fill, stroke, gradients
Structure

Layers & layout

  • Separate layers for each element
  • Guides, grids and alignment
Type

Typography

  • Readable at small sizes
  • Matches brand values

Key Terms

Vector
Graphics built from paths – scalable without quality loss.
Path
A line or shape defined by points (nodes).
Layer
A separate level in a graphic that can be edited independently.

Good Practice & Watch Out For

✔ Good practice

  • Use vector software for logos
  • Keep elements on organised layers
  • Test the logo small and in one colour

✘ Watch out for

  • Building a logo from a low-resolution bitmap
  • Over-complicated detail
  • Using a template that isn't your own work
