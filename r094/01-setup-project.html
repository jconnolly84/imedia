Before You Start: Project Setup

Set up your folder structure and create your Project Log before you do anything else.

Keep your Project Log updated Screenshot as you work Link back to brief + audience

Project Setup

  • Create a main folder for your project, then make subfolders for planning and production.
  • Save the client brief into the main folder.
  • Create a project log with a clear name.
  • Title slide must include the unit name/brief name and your full name.
Project Log evidence:
Add screenshots and explain what you did and why.

Quick checks

  • Does this link back to the client brief?
  • Does this suit the target audience?
  • Have you taken screenshots during the process?
  • Is your work saved in a sensible, organised folder?
Common mistake:
Only showing the final outcome. Record your process and explain your decisions as you go.

Why File Management Matters

Organised from the start

Professional designers set up folders before they start, so originals, edited assets, master files and exports never get mixed up.

  • Clear folder names and file names
  • Keep originals untouched; edit copies
  • Back up regularly
Folders

Separate stages

  • Originals / sourced assets
  • Edited assets
  • Master files
  • Exports
Names

Naming conventions

  • Describe the content
  • Use versions, e.g. v1, v2
Formats

Keep quality

  • Proprietary masters (e.g. PSD, AFPHOTO, SVG)
  • Lossless formats while editing

Key Terms

Master file
A high-resolution, editable file kept for future changes.
Proprietary format
A software's own file format that keeps layers and editability.
Version control
Saving numbered versions so you can go back.

Good Practice & Watch Out For

✔ Good practice

  • Keep original and edited assets in separate folders
  • Save editable master files as you work
  • Name files so anyone could find them

✘ Watch out for

  • Overwriting the only copy of an asset
  • Saving everything to the desktop or downloads
  • Flattening a file before you've finished editing
