Privacy Policy

iMedia Genius is a free revision site for OCR Creative iMedia. There are no accounts or logins for visitors, no adverts, and nothing here tracks you for marketing. This page lists exactly what gets stored or sent, and when.

Last updated 22 November 2026

If you're visiting the site

Reading the topic guides, playing the revision games, watching the videos and practising exam papers needs no sign-in and no personal details. Nothing you do is sent to iMedia Genius.

A few features save to your browser's local storage, so your work is still there next time you use the same device:

  • Guides you tick off as done, so the course progress bar remembers where you got to.
  • Your answers in the mini exams, which save as you type so closing the tab doesn't lose them.

This data stays on your device. Clearing your browser data deletes it, and it won't follow you to another device or browser.

Features for the site author's own classes

iMedia Genius is written by a teacher, and a small number of features are used only with their own classes. If you aren't in one of those classes, you won't need any of them.

  • Engagement links. These are only given out by the teacher, from the iMedia Genius worksheet app. Opening one starts a session of up to eight hours, linked to the student's name and class. During that session the site records which pages are opened, time active on each page, how much of each video and podcast is played, and game scores for the class leaderboard.
  • Exam submissions. Some exam papers have a box for a name and class and a Submit button, so students in those classes can send in answers for marking. If you aren't in one of those classes, use the papers for practice and don't submit. Your answers then stay in your browser.
  • Marking desk. The teacher signs in with a Google account to mark submissions. It isn't open to anyone else.

Engagement data and exam submissions are stored in Firebase, in Google Cloud's London region (europe-west2).

Services the site relies on

  • GitHub Pages hosts the site. Like any web host, GitHub keeps server logs, including IP addresses, for security. See the GitHub privacy statement.
  • Google Fonts provides the typefaces, so your browser downloads them from Google's servers.
  • YouTube plays the embedded videos. Most use YouTube's privacy-enhanced mode.

Links to Pexels, ChatGPT, Claude, Gemini, Copilot and NotebookLM take you to other websites. Once you're there, their own privacy policies apply.

Changes

If the site starts storing or sending anything new, this page will be updated and the date at the top will change.
