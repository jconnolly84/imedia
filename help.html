Help

This page explains how to get started with iMedia Genius and where to look if something is not working as expected.

How to use the site

  • Use the topic guides to learn or review each area of the R093 specification.
  • Use the revision games for active recall and quick checks.
  • Use mini exams, full papers, and 9-mark tools to build exam technique.

If something is not working

  • Refresh the page and try again.
  • Clear browser cache if a page looks out of date.
  • Try a different browser or device if interactive features do not respond correctly.
  • Check whether your school network blocks external video or app services.

Progress and saved data

Some features use browser storage to remember progress on the same device. If you clear browser data or switch devices, that saved progress may not follow you unless a linked account feature is used.

Teacher use

Teachers can use the topic pages, games, and exam tools for revision lessons, starter tasks, homework, intervention sessions, and independent study routines.

Need a contact section?
